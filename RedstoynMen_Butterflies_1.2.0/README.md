# RedstoynMen Butterflies — expanded

Minecraft Java 26.2 / Fabric.

## Что добавлено
- 3 вида бабочек: обычная, мирная зелёная и агрессивная красная.
- Обычные бабочки дружелюбны и не атакуют.
- Зелёные бабочки полностью мирные: не атакуют и не получают урон.
- Красные бабочки без причины атакуют живых существ поблизости, включая игроков, животных, пчёл и големов.
- Агрессивный мёд даёт Силу I, Сопротивление I и Скорость II на 1 минуту.
- Обычный мёд работает как обычный мёд по питанию.
- Бабочки собирают нектар и со временем сами создают ульи рядом с цветами.
- Ульи имеют 3 варианта: обычный, мирный зелёный и агрессивный красный.
- Мирные и агрессивные цветы используют ванильный вид одуванчика и мака, но могут висеть в воздухе без опоры.
- В мире случайно появляется заброшенная стеклянная пасека с ульями и запасами мёда.
- В пасеке шанс появления бабочки: 40% зелёная, 59% красная, 1% обычная.
- В биоме Old Growth Birch Forest (биом высоких берёз) с шансом 1% может появиться очень высокая берёза высотой 20 блоков.
- Внутри высокой берёзы сделан узкий 1-блочный лабиринт-проход, рассчитанный на маленькую бабочку; игрок в него не помещается стоя.
- Наверху высокой берёзы находится улей.
- Внутри высокой берёзы шанс каждого вида бабочки равен примерно 1/3.
- Текстуры бабочек и ульев обновлены под более ванильный пиксельный стиль.

## Сборка
GitHub Actions уже настроен на Java 25 и Gradle 9.5.1.
После загрузки репозитория открой Actions → последний запуск → Artifacts → `redstoynmen-butterflies`.
